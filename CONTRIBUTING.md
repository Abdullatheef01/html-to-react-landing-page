# Contributing

Thank you for your interest in contributing to this project.

This project focuses on converting an existing HTML landing page into a reusable and responsive **React.js + Tailwind CSS** application.

## How to Contribute

1. Check the available GitHub Issues.
2. Comment on an issue you would like to work on.
3. Wait for the issue to be assigned to you.
4. Fork the repository and create a new branch.
5. Implement the required changes.
6. Test your changes locally.
7. Create a Pull Request with a clear description.

## Guidelines

* Use **React.js** for components.
* Use **Tailwind CSS** for styling.
* Keep components clean and reusable.
* Maintain the existing design and functionality.
* Ensure responsive behavior.
* Avoid unrelated changes.
* Do not add unnecessary dependencies.

## Pull Requests

Before submitting a Pull Request, make sure:

* The application runs without errors.
* The assigned issue is completed.
* The UI works across different screen sizes.
* No unrelated files or changes are included.

All Pull Requests will be reviewed before merging.

If you have any questions, discuss them in the relevant GitHub Issue before starting major changes.
