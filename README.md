# HTML to React Landing Page Conversion

## About the Project

This project aims to convert an existing HTML landing page into a modern, reusable, and maintainable React.js application.

The current landing page is built using HTML, CSS, and JavaScript. The goal is to rebuild the same interface using **React.js and Tailwind CSS**, while preserving the existing design, content, responsiveness, and functionality.

This project is open for contributors who want to gain practical experience with React.js, Tailwind CSS, component-based development, Git, and GitHub collaboration.

## Objective

The primary objective is to transform the existing static landing page into a properly structured React application.

The final application should:

* Use React.js for component-based development
* Use Tailwind CSS for styling
* Maintain the existing visual design
* Be fully responsive across different screen sizes
* Use reusable React components
* Keep the code clean and maintainable
* Preserve the existing functionality

## Technology Stack

* React.js
* Tailwind CSS
* JavaScript
* Vite
* Git
* GitHub

## Project Sections

The existing landing page contains the following major sections:

* Navbar
* Hero Section
* About Section
* Events Section
* Schedule Section
* Registration Section
* Footer

Each section should be converted into a suitable React component.

## Contribution Guidelines

Before starting development:

1. Check the available GitHub Issues.
2. Select an issue that you want to work on.
3. Comment on the issue before starting.
4. Wait for the issue to be assigned to you.
5. Fork the repository.
6. Clone your forked repository.
7. Create a separate branch for your work.
8. Implement the assigned changes.
9. Test your changes on different screen sizes.
10. Commit your changes with a meaningful commit message.
11. Push your branch.
12. Create a Pull Request.

## Important Rules

* Do not modify unrelated sections.
* Do not introduce unnecessary dependencies.
* Use React components instead of keeping the page as a single large component.
* Use Tailwind CSS for styling.
* Keep components reusable where possible.
* Maintain the existing design unless the issue specifically requests a design change.
* Make sure the application remains responsive.
* Test your changes before creating a Pull Request.
